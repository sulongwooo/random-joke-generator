# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly. Do not open a public GitHub issue.

Instead, please email the maintainer at: **sulongwoo@gmail.com**

Please include:
- Description of the vulnerability
- Steps to reproduce it
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt of your report within 48 hours and work with you to understand and address the issue.

## Security Considerations

This project:
- Uses only public APIs without authentication
- Stores no sensitive data
- Does not collect user information
- Has no server-side processing

For security updates, watch the repository or check the release notes regularly.

## Dependencies

This project uses:
- No npm packages (zero dependencies)
- Only vanilla JavaScript
- Public APIs (Joke API v2)

All external services are third-party and beyond our control. Always verify the security of external APIs before deploying.
