# 🚀 How to Open the Website

Choose one of the methods below based on your system:

## Method 1: Direct Browser Opening (Easiest)
Simply open `index.html` directly in your web browser:
- **Windows:** Right-click `index.html` → Open with → Your browser
- **macOS:** Double-click `index.html`
- **Linux:** Right-click `index.html` → Open with → Your browser

## Method 2: Python (No Installation Required on Most Systems)

### macOS/Linux:
```bash
./start.sh
```

### Windows:
```cmd
start.bat
```

Or manually:
```bash
python3 -m http.server 8000
```

Then open: `http://localhost:8000`

## Method 3: Node.js

```bash
node server.js
```

The browser will open automatically!

## Method 4: PHP

```bash
php -S localhost:8000
```

Then open: `http://localhost:8000`

## Method 5: GitHub Pages (Online)

1. Go to repository settings
2. Navigate to "Pages"
3. Select `main` branch
4. Your site will be live at: `https://sulongwooo.github.io/random-joke-generator/`

## 🎯 Recommended: Method 1 (Simplest)

Just double-click `index.html` - it works instantly!

---

**Note:** The app requires internet connection to fetch jokes from the API.
